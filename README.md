# Hulu PET

PET（B1 Preliminary for Schools）12 周自学计划的配套小工具：每天自动排好 3 项任务，用六级箱子间隔复习代替单词听写。
纯前端 PWA，数据全部存在浏览器本地（IndexedDB）。

## 运行

```bash
npm install
npm run dev        # 本地开发
npm test           # 单元测试（调度、选词、出题、CSV、任务生成、贴纸与休息卡）
npm run build      # 产出 dist/，纯静态文件，放到任意静态托管即可
npm run preview    # 本地预览构建结果
```

部署后在 iPad Safari 或安卓 Chrome 里打开，「添加到主屏幕」即可离线使用。
注意：离线缓存和录音都要求 **https**（或 localhost）；家里的服务器如果只有 http，这两项不可用。

## 第一次使用

1. 点右上角「家长」，设置家长密码。
2. 「词表」里点「载入 12 周词表（384 词）」（`public/pet-words.csv`），或上传自己的 CSV。
   这份词表是按 12 周主题自编的 B1 常用词，不是剑桥官方词表；要增删改，编辑 `scripts/build-wordlist.py` 后运行它重新生成。
3. 孩子已经认得的词：勾选后「标为已掌握」，一个月后只抽查一次。
4. 「设置」里确认起始日期（默认 2026-11-16，第 1 周的周一）。

词表 CSV 的列顺序：

```csv
word,pos,meaning_zh,example_en,topic,week,need_spelling
abroad,adv,在国外,My cousin studies abroad.,travel,4,0
```

`week` 是 1–12，新词只会从当前周次及以前的词里出；重复导入同一个词只更新内容，不影响学习进度。

## 功能

| 模块 | 说明 |
| --- | --- |
| 今日任务 | 按周次和星期生成；周五默认最小任务日，任何一天可手动切换；周日休息；线下任务手动打勾 |
| 单词 | 箱子间隔 1、2、4、7、15、30 天；答对升一级，答错回第 1 级并在当次末尾再出现一次；每天新词默认 8 个、复习最多 40 个，多出的顺延 |
| 题型 | 1–2 级听音选义 / 看词选义；3–4 级看中文选英文 / 例句填空；5–6 级只对「需要拼写」的词出拼写题 |
| 发音 | 浏览器语音合成，英式发音（`en-GB`） |
| 口语 | 每周一张题目卡，录音、回放、保存，按日期列出 |
| 写作 | 题目卡、实时词数、本周新词提示，自动存草稿 |
| 贴纸 | 当天任务全部完成得一枚；每周 2 张休息卡，用了不算断签 |
| 家长面板 | 本周完成天数和分钟数、各熟练度词数、最常错的 20 个词、录音和作文、每日新词量、JSON 备份 |
| AI 作文反馈 | 默认关闭；开启并填入 Anthropic API 密钥后，返回 2 条优点加 1 条建议 |

孩子的界面里没有倒计时、错误计数、正确率和红色叉号；这些数字只在家长面板里。

## 隐私

除 AI 作文反馈外，应用不向外发送任何内容。AI 开关关闭时没有任何外部请求，SDK 也不会被加载。
API 密钥保存在这台设备的浏览器里（不进备份文件）；密钥放在前端并不安全，建议单独建一个低限额的密钥，或等第二版加后端代理。

## 代码结构

```
src/lib/srs.ts      六级箱子调度与每日选词（纯函数）
src/lib/quiz.ts     题型选择、选项与例句填空
src/lib/plan.ts     12 周计划与每日任务生成
src/lib/csv.ts      词表 CSV 解析
src/lib/store.ts    数据库读写：作答、任务完成、贴纸、休息卡
src/lib/db.ts       Dexie 表结构
src/pages/          Today / Practice / Speaking / Writing / Stickers / Parent
```
